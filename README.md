# ChatGPT AutoPilot

ChatGPT 웹 대화에서 사용자가 직접 시작한 뒤, 응답 종료를 감지하여 후속 프롬프트를 입력하는 Chrome 확장 프로그램 **실험용 MVP**입니다.

## 설치

1. 저장소를 다운로드하거나 `git clone`합니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 눌러 `manifest.json`이 있는 폴더를 선택합니다.
4. ChatGPT 대화를 연 뒤 확장 프로그램의 **시작**을 누릅니다. 응답 중이라면 완료 후 전송하고, 대기 중이라면 첫 프롬프트를 즉시 전송합니다.

## 주의

- 실제 ChatGPT DOM에서 동작은 아직 검증되지 않았습니다.
- 응답 종료 감지는 중지 버튼의 등장/소멸에 의존하는 초기 구현이며, 도구 승인 대기·오류를 정확히 판별하지 못할 수 있습니다.
- 반드시 최대 전송 횟수를 낮게 설정해 시험하고, 중요한 Git 변경은 수동으로 검토하세요.
- 로그인·CAPTCHA·사용량 제한 우회 기능은 제공하지 않습니다.
- 웹페이지 UI 변경과 서비스 이용 조건에 따라 자동화가 제한될 수 있습니다.
