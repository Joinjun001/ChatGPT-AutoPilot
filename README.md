# ChatGPT AutoPilot

ChatGPT 웹 대화에서 **같은 후속 프롬프트를 응답이 끝날 때마다 다시 보내**, SSalMuk MCP로 연결된 프로젝트를 브라우저 안에서 단계별로 계속 개발하게 하는 Chrome 확장 프로그램입니다. (실험용, v0.3.0)

> ⚠️ **전제 조건:** 이 확장 프로그램은 혼자서는 아무 파일도 다루지 않습니다.
> ChatGPT 대화에서 **`@SSalMuk` 플러그인으로 작업할 프로젝트 폴더를 이미 가리킨 상태**여야 합니다.
> 실제 파일 읽기·수정·테스트·커밋은 모두 ChatGPT가 SSalMuk 플러그인의 도구로 수행하고, AutoPilot은 "다음 단계 진행해" 버튼을 대신 눌러 줄 뿐입니다.

## 동작 방식

```
[사이드 패널: 시작] → 프롬프트 전송 → ChatGPT가 SSalMuk 도구로 한 단계 작업
        ↑                                              ↓
  AUTOPILOT: CONTINUE ← 응답 마지막 줄 확인 ← 응답 종료 감지
        (DONE / BLOCKED / 상태 줄 없음 → 중지)
```

1. 사이드 패널에서 **시작**을 누르면 후속 프롬프트를 ChatGPT 입력창에 넣고 전송합니다. (이미 응답 중이면 끝난 뒤 전송)
2. 응답 종료는 ChatGPT의 중지(■) 버튼이 사라지고, 화면의 응답 텍스트가 몇 초간 더 바뀌지 않는 것으로 감지합니다. (도구 호출 사이에 버튼이 잠깐 사라지거나 마지막 줄이 늦게 그려져도 오판하지 않도록)
3. 응답 마지막 줄의 `AUTOPILOT:` 상태를 읽어 계속할지 멈출지 결정합니다. 화면 HTML 구조에 의존하지 않고, 대화 영역의 보이는 텍스트에서 **방금 보낸 프롬프트 이후**에 **한 줄 전체가** `AUTOPILOT: CONTINUE`(또는 `DONE`/`BLOCKED`)인 줄만 마커로 인정합니다.
4. 계속이면 **똑같은 프롬프트**를 다시 보냅니다. 프롬프트가 "파일과 Git 상태를 보고 다음 미완료 항목 하나를 하라"는 내용이라, 몇 번을 반복해도 매번 다음 단계로 나아갑니다.

## 준비

| 항목 | 내용 |
| --- | --- |
| SSalMuk 플러그인 | ChatGPT에 앱(플러그인)으로 연결되어 프로젝트 파일 읽기·쓰기, test/build 실행, git 커밋이 가능함 |
| 대상 프로젝트 | SSalMuk이 접근할 수 있는 폴더 (예: `PerpDEX`), test/build 명령이 있음 |
| ChatGPT 대화 | 입력창에서 `@SSalMuk`을 선택하고, 어느 프로젝트에서 작업할지 한 번 알려 둔 상태 |
| (권장) 프로젝트 문서 | `ROADMAP.md`, `PROJECT_STATE.md`, `tasks/TASK-XXX/{SPEC,TODO,QA,RESULT}.md` — 없으면 첫 단계에서 만들게 됩니다 |
| Chrome | 116 이상 (사이드 패널 API) |

## 설치

1. 저장소를 `git clone`하거나 ZIP으로 내려받아 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램 로드**를 눌러 `manifest.json`이 있는 폴더를 선택합니다.
4. 툴바의 퍼즐 아이콘에서 ChatGPT AutoPilot을 **고정(📌)** 해 두면 편합니다.

업데이트 후에는 `chrome://extensions`에서 새로고침(↻)하고, 열려 있던 ChatGPT 탭도 새로고침하세요.

## 사용법

1. ChatGPT에서 `@SSalMuk`으로 프로젝트를 가리킨 대화를 엽니다.
2. 툴바의 AutoPilot 아이콘을 누르면 **오른쪽 사이드 패널**이 열립니다. 페이지의 다른 곳을 클릭해도 닫히지 않습니다.
3. 패널의 **시작 전 확인** 항목을 점검합니다.
4. 후속 프롬프트(기본값 그대로 사용 가능)와 최대 전송 횟수를 확인하고 **시작**을 누릅니다.
5. 패널의 상태·진행률·로그에서 진행 상황을 봅니다. 언제든 **중지**를 누를 수 있습니다.

프롬프트·횟수·옵션은 자동 저장되며, 프롬프트를 고친 뒤 **기본값으로 되돌리기**로 복원할 수 있습니다.

## 기본 프롬프트

기본 프롬프트는 매번 똑같이 보내도 안전하도록 설계되었습니다. 핵심 규칙은 다음과 같습니다.

- 대화 기억이 아니라 **프로젝트 파일과 `git status`** 를 기준으로 현재 상태를 판단
- 커밋되지 않은 변경이 있으면 새 작업보다 먼저 마무리
- 미완료 항목 중 **가장 앞선 것 하나만** 구현
- 프로젝트의 test/build 명령으로 검증 후, 문서를 갱신하고 바뀐 파일만 로컬 커밋
- TASK가 비었는데 ROADMAP 마일스톤이 남아 있으면 TASK로 쪼개서 이어서 진행
- 원격 push·대량 삭제·배포·비밀값 처리는 하지 않고 "사람 확인 필요"로 기록

특정 도구 이름에 의존하지 않아서, 권한이 다른 SSalMuk 버전(예: 읽기·커밋만 허용한 [ssalmuk-safe](https://github.com/Joinjun001/ssalmuk-safe))에서도 그대로 쓸 수 있습니다.
- 응답 마지막 줄에 `AUTOPILOT: CONTINUE` / `DONE` / `BLOCKED` 중 하나를 표기

전문은 [`src/defaults.js`](src/defaults.js)에 있습니다. 직접 고쳐 쓸 때도 마지막 줄 규칙은 유지하는 것을 권장합니다. 프롬프트 안에서 선택지를 안내할 때는 `AUTOPILOT: CONTINUE  (설명)`처럼 **뒤에 설명을 붙여** 마커로 오인되지 않게 하세요.

## 자동 중지 조건

| 조건 | 패널 표시 |
| --- | --- |
| 응답 마지막 줄이 `AUTOPILOT: DONE` | 완료 |
| 응답 마지막 줄이 `AUTOPILOT: BLOCKED` | 확인 필요 |
| `AUTOPILOT:` 상태 줄이 없음 (옵션, 기본 켜짐) | 확인 필요 — 도구 승인 대기나 오류일 가능성 |
| 최대 전송 횟수 도달 (기본 10, 최대 100) | 중지됨 |
| 입력창·전송 버튼을 찾지 못하거나 전송 후 응답이 시작되지 않음 | 오류 |
| 사용자가 **중지** 클릭 | 중지됨 |

## 제한 사항

- ChatGPT 웹 UI가 바뀌면 입력창·버튼 감지가 깨질 수 있습니다. 여러 selector를 fallback으로 시도하지만 보장되지 않습니다.
- 응답 종료는 중지 버튼의 유무로만 판단합니다. 도구 승인 대기는 상태 줄 확인 옵션으로 간접적으로 막습니다.
- 페이지를 새로고침하면 실행이 끊기며, 자동으로 다시 시작하지 않습니다.
- SSalMuk 플러그인에 모든 권한이 있으면 push·삭제 같은 작업을 도구가 막아주지 않습니다. 기본 프롬프트의 금지 규칙이 유일한 안전장치이니, 프롬프트를 고칠 때 이 부분은 유지하고 로컬 커밋은 직접 검토한 뒤 push하세요.
- 로그인·CAPTCHA·사용량 제한을 우회하는 기능은 없습니다. 서비스 이용 조건에 따라 자동화가 제한될 수 있습니다.

## 프로젝트 구조

```
manifest.json        Chrome MV3 설정 (chatgpt.com 한정, 사이드 패널)
sidepanel.html       사이드 패널 UI
src/background.js    아이콘 클릭 시 사이드 패널 열기
src/defaults.js      기본 프롬프트·횟수
src/sidepanel.js     설정 저장, 시작/중지, 상태·로그 표시
src/content.js       ChatGPT 화면 감시, 프롬프트 입력·전송, 마커 판독
ARCHITECTURE.md      구성 요소와 설계 원칙
ROADMAP.md           마일스톤
PROJECT_STATE.md     현재 상태
tasks/               작업 단위 문서
```
